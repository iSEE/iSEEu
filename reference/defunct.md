# Defunct functions

Pretty much as it says here. These functions are all defunct and should
not be used.

## Usage

``` r
.getAcceptablePValueFields(...)

.getAcceptableAveAbFields(...)

.getAcceptableLogFCFields(...)

.setAcceptablePValueFields(...)

.setAcceptableAveAbFields(...)

.setAcceptableLogFCFields(...)
```

## Arguments

- ...:

  Ignored.

## Value

All functions error out with a defunct message pointing towards its
replacement (if available).
